# HSD Humanities — démo

Démonstration de l'application de suivi des résultats et de l'effort (Grade 11-12, Humanities),
Collège Alpin Beau Soleil.

**Tous les élèves de cette démo sont fictifs.** L'application fonctionne entièrement dans le
navigateur : aucune donnée n'est envoyée en ligne. La démo utilise sa propre mémoire, séparée de
toute version réellement utilisée en classe.

Ouvrir directement en démo : https://jeremyesposito05-alt.github.io/suivi-hsd/#demo
